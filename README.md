# Automatic File Sorter in File Explorer

## Overview

A Python program that automatically organizes documents, media, and PDF files into separate folders based on file type.

The program:

1. Reads the files in a selected directory.
2. Identifies each file by its extension.
3. Creates destination folders when necessary.
4. Moves each supported file into the appropriate folder.

## How to Use

1. Download or clone the repository.
2. Open the notebook in Jupyter Notebook or VS Code.
3. Replace the sample directory with your own folder path.
4. Run the notebook cells.

## Tools Used

- Python
- `os`
- `shutil`
- Jupyter Notebook
